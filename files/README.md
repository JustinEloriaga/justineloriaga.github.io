Put paper PDFs, the CV, and any other downloadable files in this folder.

Link to them from a page as `/files/filename.pdf`.

**The CV goes here as `files/cv.pdf`** — exactly that name, lowercase. Two buttons link
to `/files/cv.pdf` (the home page hero and the CV page) and both 404 until it exists.

Keep filenames lowercase with hyphens — no spaces, no version numbers in the
public name (`fed-information-effect.pdf`, not `fed_information_paper-4.pdf`),
so a link you give someone today still works after the next revision.
